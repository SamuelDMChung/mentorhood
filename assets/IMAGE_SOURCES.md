# Source-image inventory

See [`ORIGINAL_IMAGE_URLS.json`](./ORIGINAL_IMAGE_URLS.json) for the 51 distinct original Wix photo/logo URLs referenced in this version. The file is a URL catalog, **not a copy of any image**. Each URL was identified from the publicly accessible Mentorhood Math site or its previously prepared V2 starter; source direct download was unavailable during this reconstruction.

Image loading on the deployed site depends on Wix continuing to serve the original files. The browser shows a placeholder when an image fails.

**Before production:** Export the owner's approved image files from Wix or the original asset library, put them in `assets/images/`, and replace URLs in `index.html`. Verify rights and photo releases for photos featuring children or teachers.
