# Images used in the public demo

The HTML currently references images on the **original Mentorhood Math Wix media CDN**. These images are *linked*, not copied into this ZIP. The demo should not assume that they will be permanently available after the old Wix site is discontinued.

Before the actual launch, obtain approval to reuse the images, export the full-resolution files from the site owner's Wix Media Manager, save them in `assets/`, and replace the remote `src` URLs in `index.html` with relative filenames. Confirm photographer, parent/guardian and model permissions where children appear in photos.
